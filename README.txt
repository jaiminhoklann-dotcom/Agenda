Agenda Shows v2

Inclui:
- Calendário mensal completo como tela principal.
- Todos os dias visíveis, inclusive dias adjacentes do mês.
- Visualização semanal opcional.
- Toque em qualquer dia para adicionar um freela ou compromisso.
- Cadastro de clientes.
- Botão + Cliente durante o cadastro de um freela.
- WhatsApp opcional por cliente.
- Edição e exclusão de clientes.
- Cadastro de tipos de trabalho e respectivos valores.
- Edição e exclusão dos tipos de trabalho.
- Trabalhos iniciais: Montagem meio período R$200, Montagem dia todo R$400, Técnica R$450, Desmontagem R$200.
- Seleção de vários trabalhos com soma automática.
- Valor final editável.
- Compromissos pessoais sem valor.
- Fechamento semanal por cliente.
- Relatório semanal pronto para WhatsApp.
- Marcação de recebimento.
- Botão X no canto superior de todas as janelas.

Observação: os dados ficam armazenados localmente no navegador/aparelho. A sincronização automática com Google Calendar ainda requer integração com a API do Google.
